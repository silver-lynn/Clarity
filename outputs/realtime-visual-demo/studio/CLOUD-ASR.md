# Clarity 云端语音识别

默认服务为火山引擎「豆包流式语音识别 2.0」。本地识别保留为手动选择的备用选项，不自动降级。

## 开通与使用

1. 在火山引擎控制台开通「流式语音识别 2.0」按时长服务，并确保有可用额度。资源 ID：`volc.seedasr.sauc.duration`。
2. 在 https://console.volcengine.com/speech/new/setting/apikeys?projectName=default 创建 API Key。这里使用新控制台的 API Key，不是 Jev 密钥，也不是火山账号的 AccessKey/SecretKey。
3. 正常启动 Clarity，或单独运行项目中的 `start-cloud-asr.cmd`。桥接服务仅监听本机 8002 端口，不加载本地识别模型。
4. 刷新工作台，点击开始讲述，在设置中填入 Key 并应用，再点击开始讲述。
5. 停止录音会发送剩余音频，等待尾句确认后关闭云端连接。

默认勾选“在此设备记住密钥和服务设置”，使用 Windows 当前用户 DPAPI 加密保存在网页目录外。刷新时自动恢复；取消勾选并应用后仅当前页面有效。“清除已保存密钥”会删除本机保存和当前页面密钥。密钥不写日志、不进入演讲导出或浏览器 localStorage。不要将 Key 发到聊天中。

录音音频与有限量的识别热词会发往火山引擎；背景资料正文不会发送。服务按账号实际规则收费，2026-09-27 官网展示流式识别约 1 元/小时，以控制台订单为准。

## 实现边界

- 音频：16 kHz、单声道、16-bit PCM，聚合成约 200 ms 数据包。
- 双向流式预览 + 整句二次识别；只有 `definite` 确认句进入演讲结构。按开始时间保持句子身份，后续修订更新原句。
- 实时字幕优化：首字加速设为 5，停顿判定设为 500 ms，起始强制语音时长设为 1000 ms。预览首字可能更容易修订，仍保留二遍校正。实时全文比分句数组先更新时，立即展示可明确分离的新尾部文字。上述参数不是端到端延迟保证。
- 本机健康接口记录无原文的更新计数与时间间隔，便于区分上游返回慢和显示问题；首次返回时间包含用户开始录音后的静音。
- 开启标点与数字规范化，关闭口语顺滑，减少主动删改原话。
- 热词采用保守容量限制，超出部分在工作台提示，不承诺每个同音字都能纠正。
- 密钥、额度、网络异常明确报错，不自动重试付费连接。
- 当前已通过模拟上游的协议、尾句、修订、去重、连接来源限制、密钥保护和浏览器交互测试。尚未获得真实 API Key，因此未完成真实付费服务连通性、准确率和延迟验证。
