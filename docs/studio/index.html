工作台设置

使用 Windows 当前账户加密保存，不写入演讲备份。共用电脑可取消勾选，仅本次使用。

人物关系模式

内置《甄嬛传》常见人物与称呼，例如莞嫔 → 甄嬛、皇上 → 皇帝。只提取讲述内容，不自动补充剧情；代词和复杂多人句可能无法识别。

语音识别

在火山引擎开通「流式语音识别 2.0」按时长服务，然后创建 API Key。打开密钥控制台 ↗

开始讲述后，音频和选中的识别热词会发送至火山引擎；背景资料正文不发送。实时显示预览，停顿后确认整句。按官方当前价约 1 元/小时，实际以控制台为准。停止录音即断开云端连接。勾选记住后，刷新会自动恢复；密钥不进入演讲导出。首次使用请运行 start-cloud-asr.cmd（正常启动器会自动启动）。

离线备用：本地实时预览与 SenseVoice 整句确认。热词仅对预览加权，需启动本机识别服务。

语义理解

使用 jev-latest，在有原话依据的候选画面中选择图形、大字幕或关键结论；不生成新文字。当前基础图形保留为候选，数值图须有明确数字与单位。启用后最近 8 段原话及当前画面会发送至 TypeSafe（背景资料不会发送）。低置信度或请求失败时保留基础画面。密钥可在此设备加密保存，不进入演讲导出。

模型需允许跨域请求。启用后将发送最近原话与当前画面；使用远程地址时，这些文字会离开本机。密钥可在此设备加密保存，不进入演讲导出。请求失败自动使用基础模式。
